# Backlog: ideas we are not building now

Each one would follow the same rule as the rest of the app: every fact comes from a source, with its link and checked-at time.

- **Calendar export and reminders**: the kept experiences go into the phone's calendar with their time and address, so the plan is there on the day and a reminder comes before each start.
- **Offline brochure**: the page and map are saved on the phone, so the plan still opens abroad with no signal or data roaming. The PDF covers only part of this.
- **Packing lists from weather and indoor/outdoor tags**: the forecast for the trip dates and each kept item's indoor/outdoor tag say what to bring, such as an umbrella for the outdoor day or layers for a cold evening.
- **Local essentials (plugs, emergency numbers, transport)**: these are the practical facts a first-time visitor looks up anyway. One page per destination, each fact with its source, saves those searches.
- **Travel-documents folder**: tickets and confirmations sit next to the plan, so everything needed for a day is in one place.
