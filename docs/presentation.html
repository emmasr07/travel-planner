The problem

Planning a trip means a dozen tabs, and an AI that can invent the details.

Too many sources

Tours on one site, opening hours on another, prices in another currency, a map somewhere else.

Chatbots sound sure

A language model can write a confident price, season or minimum age that no page actually states.

Budgets break late

You find out the plan is over budget only after you have chosen everything.

Our thesis

Let the AI choose and explain. Let the code check and count. Let a second check judge the first.

We believe

Travellers reach a plan they trust faster than planning by hand, because an agent can read many messy pages quickly and pull out what fits their dates, group and budget.

It breaks if

The agent makes facts up. So every fact carries its source and the time it was checked, the code does all arithmetic and checks, and facts are re-checked before an item is called verified.

We know it works if

On experiences checked by hand against their sources, the ones marked verified are right at least 19 times out of 20.

Scope

Experiences only: tours, food, culture, nature, nightlife. No flights or hotels. Any destination.

How it works

Seven steps from questionnaire to brochure.

You

Questionnaire

Destination, dates, group, age, interests, budget, pace.

Sources

Real data

Viator, Geoapify (OpenStreetMap), Tavily web search, Frankfurter exchange rates.

AI agent

Researcher

Picks 10–15 experiences, copies facts with their source, suggests the best time and why.

Code

Checks

Schema, budget, season, age, opening hours, overlaps, pace, closures, accessibility.

Code + AI

Verifier

Code re-asks Viator and Geoapify; a second agent re-reads web pages. Verdict per item.

You

Choose

Keep, remove, swap, change times, ask for something last-minute.

Code

Brochure + PDF

Day by day, with a map, prices, sources and booking links. No AI.

What testing revealed

Real data found problems our sample data never showed.

A group price counted per person

fixed

A €360 private tuk-tuk tour would have cost a group of 4 €1,440 in the budget.

A guessed minimum age

fixed

"Adult (18–99)" was read as "18+", which would have hidden the Vatican Museums from families.

A closed museum suggested

fixed

The source said "Encerrado temporariamente". Closed places are now rejected, in six languages.

The source itself was wrong

caught by hand

OpenStreetMap lists Casa Noha in Matera at "Recinto Canove"; the real address is "Recinto Cavone".

The verifier was blocked

fixed

Viator pages refuse automated readers, so the code now re-checks API facts itself.

The same place three times

fixed

The Colosseum appeared three times in one Rome trip. Items within 15 m in the same category now count as one place; repeats become alternatives.

Limits and next steps

What we would do next.

Known limits

  • Items with no price online are shown but not counted in the budget.
  • Complex opening hours (seasonal, holiday rules) stay "to check".
  • The public version runs from a laptop, so it is online only while that laptop is on.
  • The PDF font does not cover Japanese, Chinese or Arabic names.

Ideas from our team

  • Calendar export and reminders.
  • Offline access to the brochure.
  • Packing lists from weather and indoor/outdoor tags.
  • Local essentials: plugs, emergency numbers, transport.
